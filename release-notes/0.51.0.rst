0.51.0 (2026-10-22)
===================

Upgrade Notes
-------------

- `DynamicCircuitInstructionDurations`, which was previously deprecated, is now removed.
  So are the `durations` arguments of `PadDynamicalDecoupling`, `PadDelay`, and `BaseDynamicCircuitAnalysis`. (`3381 <https://github.com/Qiskit/qiskit-ibm-runtime/pull/3381>`__)
- The ``post_selection`` field of :class:`.NoiseLearnerV3Options`, which was previously deprecated, has been
  removed. (`3466 <https://github.com/Qiskit/qiskit-ibm-runtime/pull/3466>`__)


Deprecation Notes
-----------------

- :class:`~qiskit_ibm_runtime.noise_learner.NoiseLearner` is deprecated.
  Please use :class:`~qiskit_ibm_runtime.NoiseLearnerV3` instead. (`3409 <https://github.com/Qiskit/qiskit-ibm-runtime/pull/3409>`__)


New Features
------------

- :meth:`.Executor.run` now accepts a :class:`samplomatic.quantum_program.QuantumProgram`
  as a valid input. It is automatically converted to a :class:`.QuantumProgram` using
  the new public method :meth:`.QuantumProgram.from_` when run. (`3403 <https://github.com/Qiskit/qiskit-ibm-runtime/pull/3403>`__)
- :meth:`.Session.details` and :meth:`.Batch.details` now include a ``timestamps`` entry with
  the list of state transitions of the session, if available. Each entry is a dictionary with the ``status`` and
  the ``timestamp`` of when the session transitioned into it. (`3426 <https://github.com/Qiskit/qiskit-ibm-runtime/pull/3426>`__)
- The :meth:`~qiskit_ibm_runtime.QiskitRuntimeService.backends` and the
  :meth:`~qiskit_ibm_runtime.QiskitRuntimeService.jobs` methods now allow including mock backends
  and jobs from mock backends via the ``include_mocks`` argument. By default, such backends and mocks
  will be excluded from the returned results. :class:`~qiskit_ibm_runtime.IBMBackend` now also has a
  ``is_mock`` property that returns whether the backend is a mock device. (`3433 <https://github.com/Qiskit/qiskit-ibm-runtime/pull/3433>`__)


Bug Fixes
---------

- In local testing mode, ``job.metrics()`` now returns the same layout as jobs run on IBM Quantum Platform:
  timestamps are ISO 8601 UTC strings, and ``usage`` contains ``qpu_charge_time_seconds`` and ``status``
  instead of ``quantum_seconds`` and ``seconds``. The obsolete ``bss`` entry is no longer returned. (`3434 <https://github.com/Qiskit/qiskit-ibm-runtime/pull/3434>`__)
- Fixed a bug that was causing the invalid circuits that contained
  a :class:`.GlobalPhaseGate` to be generated by the
  :class:`.FoldRzz` transpiler pass and the registered function in
  Qiskit's :attr:`.WrapAngles.DEFAULT_REGISTRY` used by the transpiler
  when targeting IBM backends with that have :class:`.RZZGate` support
  in the ISA. (`3489 <https://github.com/Qiskit/qiskit-ibm-runtime/pull/3489>`__)
