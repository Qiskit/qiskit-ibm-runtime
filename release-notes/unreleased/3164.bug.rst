:meth:`.FakeProviderForBackendV2.backends` now also returns 8 fake backends that were
importable from :mod:`qiskit_ibm_runtime.fake_provider` but missing from the provider's
backend list, in addition to the ones it already returned: :class:`.FakeAachen`,
:class:`.FakeBerlin`, :class:`.FakeBoston`, :class:`.FakeBrussels`, :class:`.FakeKingston`,
:class:`.FakeMiami`, :class:`.FakePittsburgh`, and :class:`.FakeStrasbourg`. Previously,
calling ``FakeProviderForBackendV2().backend(name="fake_kingston")`` (and the other 7)
raised a ``QiskitBackendNotFoundError`` even though the backend classes existed.
